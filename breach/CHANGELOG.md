# Changelog — BREACH // 2099

## [1.0.0] - 2026-10-14

### Added
- Initial release of **BREACH // 2099** (`breach/`).
- Custom **WebGL2 GLSL ES 3.00 2.5D Normal-Mapped Deferred Lighting Shader** with world-space normal vector rotation on 360°-aiming sprites, Blinn-Phong specular highlights, and dynamic point-light accumulation.
- Real-time **2D Raycast Visibility Polygon & Shadow Map (`u_visTex`)** occluded by walls and closed blast doors.
- **3 Tactical Weapons**: Silenced Flechette Pistol (`[1]`), Ricochet Smart-SMG (`[2]`), and Door-Breaching Gauss Scattergun (`[3]`).
- **Door Kick / Breach Mechanic (`[E]` / `[F]`)** that blows closed blast doors off their hinges and stuns/damages guards in the blast cone.
- **Adrenaline Overclock (`[SPACE]` / `Right-Click`)** tactical bullet-time slow-motion with cyan neural-grid post-processing.
- **3 Hand-Crafted Spire Campaign Floors** (`01 // KOWLOON CHECKPOINT`, `02 // CRYO-VAULT SUB-44`, `03 // EXECUTIVE SKY-PENTHOUSE`) plus a deterministic **Daily Seeded Contract** mode.
- Persistent floor decals (spent brass casings, shattered cyan glass shards, and neon-crimson/coolant blood pools) and procedural WebAudio SFX.
